# Recorded music beds (user's own library)

Use one instead of the synth bed: `"music": {"track": "greek_folk", "start": 0, "stops": [[30.2, 30.9]]}`.
`start` = where in the track to begin (s). Tracks shorter than the video loop with a 1 s crossfade;
the same ducking under the voice and the same `stops` (silence beats) apply. Files: mono 48 kHz, cut to 90 s max.

| Track | Mood / use |
|---|---|
| `greek_folk` | Ancient-Greek folk - default for light or adventurous myths |
| `celtic_harp` | Gentle, haunting harp - sad or tender stories |
| `calm_ambient` | Soft, neutral bed - explanations, calm stories |
| `medieval_ambient` | Old-world, warm - kings, palaces, villages |
| `dark_mystery_piano` | Mystery, a secret, a crime |
| `cinematic_tension` | Building danger, chases, plots |
| `epic_action` | Battles, heroes, gods fighting |
| `dark_fantasy_synth` | Underworld, monsters, curses |
| `dark_ambient` | Night, eerie places |
| `horror_atmosphere` | Scary myths, creature reveals |
