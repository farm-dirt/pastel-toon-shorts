# Content playbook — categories, ideas, scripts

## What works on YouTube Shorts (use when recommending)
Shorts are swiped in < 2 s, so the first frame + first sentence must create a question.
Retention comes from a clear story shape and a payoff near the end that rewards staying; loops
(last line flows into the first) increase rewatches. Animation is strongest where live footage
can't easily go: history, "what if", inside-the-body/how-it-works, exaggerated comedy.

## Recommended categories (pitch 6-8, explain each in one line)
| Category | Why it suits Shorts + this 2D style |
|---|---|
| Weird-but-true history | Built-in curiosity hook ("In 1932 Australia lost a war… to birds"); characters act it out. |
| Strange laws & rules | Instant "wait, what?" hook, short, easy twist ending. |
| How-it-works in 40 s | Educational value + satisfying visual explanation (props, signs). |
| Psychology / money tricks | Relatable (shops, prices, habits); Mr. Bramble's shop is a ready set. |
| Animal facts with a twist | Shareable, family-friendly; easy props/sound gags. |
| Myth vs fact | Strong hook ("You've been doing X wrong"), clear payoff. |
| Mini comedy sketches | Pure physical comedy like the reference; no facts needed, high rewatch. |
| Local culture & legends (e.g. Philippines) | Underserved niche, strong identity, the user's earlier topic. |
Pick one top recommendation and say why (given the user's goals and limited time).

## Idea card format (10 per category)
**Title** (≤ 60 chars, curiosity) · **Description** (1-2 lines) · **Hook** (the exact first line
+ first image) · **Story potential** ★1-5 with reason · **Animation fit** (which cast, locations,
gags). Facts must be verified with a web search before pitching.

## Script template (30-55 s, ~2.6 spoken words per second)
| Section | Time | Job |
|---|---|---|
| Hook | 0-2 s | A question or impossible-sounding claim + strongest image. No "hi guys". |
| Setup | 2-10 s | Who/where/what they want. One location. |
| Escalation | 10-30 s | 2-3 beats, each funnier/bigger; a cut every 1.5-3 s. |
| Twist / payoff | 30-45 s | The surprising fact or punchline; freeze/hold beat. |
| Button | last 2-4 s | Tag joke, or a line that loops back to the hook. Optional short CTA ("follow for part 2") only if natural. |
For each section write: Narration · Est. duration · Visuals · Character actions · Transition.
Write narration for the ear: short sentences, one idea each, clear pause between sentences
(helps timing). Avoid tongue-twisters, long numbers (say "almost twenty thousand"), and abbreviations
the narrator might read differently.

## Voice-over instructions to give the user
Read `script/script.txt` exactly; MP3 or WAV; quiet room; a short breath between sentences;
ElevenLabs or own voice both fine. Upload the file here when done.
